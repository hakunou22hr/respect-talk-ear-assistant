# Respect Talk AI

iPhoneとBluetoothイヤホンで利用する、対面会話支援専用のPWAです。相手の日本語の発言を認識し、感情と会話意図を端末上のルールで分析して、ユーザーが次に言う短い返答案を耳元へ読み上げます。

AIと直接会話するチャットではありません。外部AI APIやAPIキーを使用せず、Web Speech API（音声認識・音声合成）とローカル処理だけで動作します。

## 起動

```bash
npm run build
npx serve dist
```

iPhone SafariではHTTPSで開き、共有メニューから「ホーム画面に追加」を選択してください。Bluetoothイヤホンは先にiOS側で接続・音声出力先として選択します。

## 注意事項

- Safariの音声認識対応状況や権限設定によっては、音声認識を利用できない場合があります。その場合もデモ会話テストは利用できます。
- 発言内容はサーバーや有料APIへ送信しません。ただし、ブラウザのWeb Speech APIの内部実装はOS・ブラウザに依存します。
- 本アプリの提案は会話の補助であり、医療・心理・緊急時の専門的助言ではありません。
