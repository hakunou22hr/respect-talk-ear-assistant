# Respect Talk AI v2

iPhoneとBluetoothイヤホンで使う、対面会話支援PWAです。直近の会話を踏まえて相手の感情・意図・求めていること・推奨行動を判断し、口に出しやすい短い返答案を最大3件提示します。有料API、APIキー、ユーザー登録は不要です。

## 採用方式

### Transformers.js + Qwen2.5-0.5B-Instruct

ローカル生成には **Transformers.js 3.7.3** と **`onnx-community/Qwen2.5-0.5B-Instruct` のq4量子化版**を採用しました。Qwen2.5は多言語モデルで日本語を扱えます。モデルは約5億パラメータ、初回ダウンロードの目安は**約400MB**です（Transformers.js・トークナイザー等を含む実通信量は配布元の更新やブラウザキャッシュ状態で変わります）。大きな通信を勝手に始めず、「生成AIモデルを準備」を押した後だけ取得します。

- WebGPUが使えるブラウザではWebGPU、使えない場合はWebAssembly (WASM) を選びます。
- 静的ホスティングだけで動くためGitHub Pages/PWAと共存できます。モデル本体は配布元から取得され、ブラウザのキャッシュへ保存されます。
- iPhone SafariではWebGPUの公開状況がiOS/Safariバージョンに左右されます。WASM fallbackはありますが、約400MBの取得・展開と生成には大きなメモリと時間が必要です。全iPhoneでの実用速度や安定動作を保証するものではありません。
- WebAssembly非対応、メモリ不足、ネットワーク失敗、モデル初期化失敗、生成/JSON解析失敗時もアプリを止めず`coach.js`へfallbackします。

### WebLLMとの比較

WebLLMはGPU向けに最適化された有力な方式ですが、WebGPUが必須となる構成のため、Safari/iOSのバージョン差が大きい本アプリでは採用しませんでした。Transformers.jsは同じコードでWebGPUとWASMを選べるため、低速でもルールベースへ安全に戻れることを優先しました。ローカルLLMが厳しい端末では、診断スイッチを「ルールベース」にして既存機能を使う方法が無料かつ最も確実です。

## 会話処理

1. Web Speech APIで日本語を認識します。
2. 最新6件（最低要件の5件以上）の「相手の発言 / AI提案」をメモリ上だけに保持します。再読み込みすると消えます。
3. モデル準備済みなら履歴と最新発言をローカルLLMへ渡し、感情、意図、ニーズ、10種の推奨行動、10～35文字の候補（最大3件）をJSONで生成します。
4. 未準備/失敗/手動ルールモードでは既存の`src/coach.js`が即時に候補を返します。生成待ちの短い相槌にも同ルールを使い、15秒のクールダウンを設けています。
5. 自動読み上げがONなら候補1をSpeechSynthesisへ渡します。各候補の🔊でも選んで再生できます。読み上げ開始前に音声認識を停止し、終了後だけ再開するため自己音声の再認識ループを防ぎます。

画面の音声診断では、音声認識成功、ローカルAI入力、AI開始/完了、生成時間、生成結果、SpeechSynthesis開始/終了を確認できます。「自動 / ローカル生成AI / ルールベース」の診断スイッチで実機比較もできます。

## 起動

```bash
npm test
npm run lint
npm run build
npx serve dist
```

iPhone SafariではHTTPSで開き、共有メニューから「ホーム画面に追加」を選択してください。Bluetoothイヤホンは先にiOS側で接続し、音声出力先として選択します。まず音声テスト、次に手動解析、最後に対話サポートの順で確認してください。ローカルAIを試す場合は、十分な空き容量・安定したWi-Fi・新しいiOSで「生成AIモデルを準備」を明示的に押してください。

## プライバシーと制約

- 会話テキストをOpenAI、Gemini、Claude等の生成AI APIへ送信しません。モデルファイル取得時にはHugging Face/jsDelivrへの通信が発生しますが、会話内容はその取得リクエストへ含めません。
- **すべての音声処理が完全に端末内とは断定できません。** Web Speech APIの音声認識処理はブラウザ・OS・設定に依存し、ベンダーのサーバー処理となる可能性があります。SpeechSynthesisの音声も端末環境に依存します。
- ローカル生成結果は誤ることがあります。本アプリは会話補助であり、医療・心理・緊急時の専門的助言ではありません。
- iPhone Safari/GitHub Pages上でモデルの初回ロードを自動試験するCIはありません。実機ごとのWebGPU/WASM、メモリ、速度は画面上の機能診断と生成時間で確認してください。
