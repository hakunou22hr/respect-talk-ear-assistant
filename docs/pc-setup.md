# 自宅PCで使うGemini版JARVIS

Web公開は不要です。Windows/Mac/Linuxの自分のPCでサーバーを起動し、ChromeまたはEdgeから音声・手入力で使います。Geminiへの接続にはインターネットが必要です。

## 初回の準備

1. [Node.js公式サイト](https://nodejs.org/) から **24 LTS** をインストールしてください。最低対応は22.9です。
2. PC版のZIPを展開します。`package.json`、`server`、`src`、`start-pc.cmd`が同じフォルダーにあることを確認します。
3. [Google AI Studio](https://aistudio.google.com/apikey) で自分のGemini APIキーを取得します。無料枠・有料枠の条件と利用制限はGoogle側で確認してください。
4. `.env.example` をコピーし、名前を **`.env`** にします（`.env.txt`ではありません）。
5. `.env` をテキストエディターで開き、`GEMINI_API_KEY=replace_with_your_key` の右側だけを自分のキーに置き換えて保存します。キーはチャットやGitHubに送らないでください。

Windowsで `start-pc.cmd` を最初にダブルクリックすると、未作成の場合だけ`.env`を作り、メモ帳で開きます。APIキーを設定して保存した後、もう一度ダブルクリックしてください。フォルダーがOneDrive等の同期対象なら、`.env`も同期され得るため保存場所を確認してください。

## 起動と対話

Windowsは `start-pc.cmd` をダブルクリック。Mac/Linuxはフォルダーで `bash start-pc.sh` を実行します。全OSで次のコマンドも使えます。

```bash
npm start
```

通常の利用に依存パッケージのインストールは不要です。起動したターミナルを開いたまま、自分のPCで `http://localhost:8787` を開きます。

1. 「Gemini設定を確認」を押す。これはPC側のキー登録有無を調べるだけで、Googleでの生成は行いません。
2. 「会話テキストのGoogle送信」をONにする。
3. 「Geminiを選ぶ」を押す。
4. 対話の種類を「JARVISと直接話す」にする。
5. マイクの利用を許可し「● 対話開始」を押して話す。

直接対話では自分の質問へJARVISが短く答えます。「私が話す」で読み上げを止めて話せます。相手との会話で耳元の返答案を使う場合は「相手との会話を支援」を選びます。

音声認識が使えない場合は手動入力欄から「JARVISへ送信」を押せます。手動入力はテスト用の一時的な対話で、実発言の議事録へ自動追加しません。手動入力の返答は画面表示し、🔊で読み上げできます。

「■ 対話終了」で終了し、必要なら履歴編集・議事録を作成します。議事録はGeminiへ送らず、既存のローカルAIまたは実発言抽出で作成します。Google APIキー未設定・利用制限・通信失敗の場合は画面に理由を表示してルールに戻ります。

サーバー停止はターミナルでCtrl+C。APIキー・モデル・上限を変更したら再起動してください。再読み込み後、Google送信は再びOFFです。

## 保存・費用・送信の範囲

- 会話・録音・議事録はブラウザのIndexedDBに保存します。Chrome/Edge、localhost/127.0.0.1、ポート番号が変わると別の保存場所になります。継続利用は同じブラウザと `http://localhost:8787` を使ってください。
- AIの返答は実発言と別データです。直接対話の文脈には使いますが、会話議事録へ混ぜません。読み上げ中に認識した声は確認待ちです。
- Geminiモードでは直近8件までのテキストをGoogleへ送ります。録音ファイルや議事録は送りません。ブラウザ標準SpeechRecognitionは別途ベンダーへの音声通信があり得ます。
- `.env`の初期モデルは `gemini-2.5-flash-lite`。入力と出力の量で課金されます。無料枠のデータ利用条件、有料枠の条件は [Google公式料金表](https://ai.google.dev/gemini-api/docs/pricing) を確認してください。
- 初期上限は1日200回・1分20回。`.jarvis-data/usage.json`には回数だけを保存し、再起動しても保持します。日次リセットは日本時間9時。失敗・取消も回数に含みます。Googleアカウント全体の金額上限ではありません。
- サーバーは127.0.0.1だけで待ち受け、インターネットや自宅LANへ公開しません。APIキーをブラウザへ渡さず、`.env`とサーバーファイルはHTTP配信しません。

## 困ったとき

- 設定ありなのに返答が出ない：画面のGemini状態を確認します。「設定あり」はキーの存在だけを意味し、有効性・課金設定・対象モデルの利用権限は実際の返答生成で確認します。
- Google利用制限：無料枠の制限またはアプリの上限です。Google AI Studioの利用状況と`.env`の上限を確認します。無条件の自動再試行はしません。
- マイクが動かない：Chrome/Edgeのマイク許可、PCの入力先を確認します。ブラウザ差があるためまず手入力で接続を確認してください。
- 音声が返ってこない：自動読み上げ、OSの音声出力、音量を確認します。
- 以前の画面が出る：PC版のURLか確認し、関連タブを閉じて開き直します。保存データを消す前に確認してください。

検証は模擬Google応答・音声APIを使った自動テストです。実Gemini APIの応答品質・実マイクとイヤホンの速度は、自分のAPIキーを登録後に確認してください。
